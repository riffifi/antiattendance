The `aa.` lettermark uses outlined Geist Pixel Square glyphs from Vercel's geist-font repository (commit 10dc7658f13c38a474cde201bb09a4617267545b). See Geist-OFL.txt for the SIL Open Font License.

app_icon.svg is the white-background launcher source; app_icon_foreground.svg, app_icon_monochrome.svg and brand.svg are transparent. Regenerate platform launcher assets with `dart run flutter_launcher_icons` after updating the PNG sources.

legacy_brand.svg preserves the original app artwork for the reverse face of the interactive About badge. brand.svg uses a cropped viewBox for in-app placement; launcher artwork retains its square canvas.
